점검 결과

Consumer, 특히 PCA II의 폭넓은 소비·고용·심리 묶음에서 변화와 불안정성이 가장 큽니다. Export는 로딩 방향이 거의 유지됩니다. 영국 III Consumer는 기존 계수부터 모두 양수여서, 같은 상관행렬에서 음수 제약만 해제해도 계수가 사실상 같습니다. 이번 점수 하락은 제약 해제만으로 설명되지 않습니다.

경제적 방향 문제는 남아 있습니다. 현재 PCA II의 원자료 방향 반영 실업률 계수는 영국 −0.071이지만, 호주 +0.208·프랑스 +0.096입니다. 일반 PCA가 공통 움직임을 찾는다는 사실이 모든 지표의 경기 부호를 보장하지 않습니다. 부호가 직관과 다르다는 이유만으로 코드 오류라고 판단할 수는 없지만, 경기 강약 지표로 사용할 때 별도 검토가 필요합니다.

전체 50개 부문(II 28, III 22)을 점검했습니다. 프랑스 II의 Capex·Export는 단일지표여서 다변량 PCA가 아니며, 독일·일본 III의 Housing은 없습니다. 지표·GDP 가중치·원자료는 바꾸지 않았습니다. 현재 점수·계수와 기존 미국·영국 점수를 원자료에서 다시 계산해 일치함을 확인했습니다.

상관계수 절댓값 ≥0.98, 공통 관측 ≥60개월인 쌍입니다. 서로 다른 개념의 총계·부분계열도 포함되므로 자동 삭제 대상이라는 뜻은 아닙니다. 같은 경제 현상에 여러 칼럼이 붙으면 그 현상이 PC1을 더 많이 좌우할 수 있어 검토 대상으로 표시했습니다.

통계적으로 어떻게 해석해야 하나

1. 로딩과 실제 기여분은 다릅니다. 이 코드의 loading은 단위 고유벡터 v의 성분입니다. 흔히 요인분석에서 말하는 변수–요인 상관과도 구분해야 합니다. 현재 부문 점수는 (Σ 관측 vᵢzᵢ / √관측수 − 출력평균) / 출력표준편차입니다. 따라서 로딩이 거의 같아도 입력 z와 출력 기준이 바뀌면 점수가 크게 바뀝니다. vᵢ²는 벡터 구성 비중일 뿐, GDP 기여율이나 해당 지표의 독립적인 설명분산 비중이 아닙니다.

2. 설명분산은 예측력 검증이 아닙니다. 현재 PC1 설명분산은 보정된 상관행렬에서 λ₁/Σλ입니다. 기존 방식은 제약 벡터의 Rayleigh 몫/행렬 대각합입니다. 두 방식은 행렬 자체가 달라 값이 커졌다고 GDP 설명력·예측력이 좋아졌다고 할 수 없습니다. 동일한 기존 행렬에서 제약만 해제한 설명분산 차이만 제약 효과로 비교할 수 있습니다.

3. 표본 길이와 결측이 중요합니다. 상관을 지표 쌍별 공통 관측으로 계산하므로 하나의 동일한 균형 표본의 공분산과 다릅니다. 현재 Consumer II의 상관행렬 보정 크기(Frobenius 상대 노름)는 캐나다 13.0%, 독일 10.3%, 미국 5.8%입니다. 반올림 오차 수준으로 보기 어렵습니다. 전체 기간이 길어도 영국 Consumer 전체 지표 공통 관측은 68개월, Capex는 47개월뿐입니다. 표본·결측 처리 민감도를 별도로 봐야 합니다.

4. 시계열의 독립 관측 가정을 쓰지 않았습니다. 월별 자료의 자기상관과 전년비 변환의 중첩을 고려해 월을 하나씩 섞는 대신 24개월 연속 블록 300회, 12개월 블록 150회를 재표본화했습니다. 결측 패턴도 함께 이동합니다. 구조 변화·비정상성·짧은 중첩 표본·보정 행렬 때문에 이 결과를 엄밀한 p값이나 확정적 신뢰구간으로 부르지 않습니다. 실패한 재표본 수도 표시합니다. 블록 길이에 따라 결과가 달라지면 그 자체를 불안정성 신호로 봅니다.

5. 우선 점검 대상. Consumer II의 호주·프랑스 실업률 역방향, 캐나다 임금 역방향과 결측 민감도, 일본·호주의 작은 PC1–PC2 간격을 우선 검토할 필요가 있습니다. 영국 Housing의 매물재고는 경제적 해석이 모호하고 표본에 따라 부호가 바뀝니다. III Consumer는 이번 진단에서 II보다 대체로 안정적이지만, 고용 정보가 빠지고 지표가 적어 안정적일 수도 있으므로 경제 전체를 더 잘 설명한다고 결론 내릴 수 없습니다. 전처리의 정상성·구조 변화에 대한 정식 검정과 GDP에 대한 실시간 빈티지 검증은 이번 점검에 포함하지 않았습니다.
