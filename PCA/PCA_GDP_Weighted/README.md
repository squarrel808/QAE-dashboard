## Momentum 변경 · 2026-10-28

Momentum = 완성된 YoY PCA의 최근 3개월 평균 − 직전 3개월 평균. 백분율 변화나 로그변화가 아닌 지수 포인트 차분이다. 별도 PCA 재추정과 재표준화는 하지 않는다. 주 PCA의 24개월 반감기는 유지하며, 과거 독립 Momentum의 12개월 반감기는 새 표시값에 사용하지 않는다.

종합지수·블록지수·GDP 가중 적용 후 기여분을 각각 같은 방식으로 차분한다. 따라서 기여분 합은 종합 Momentum과 일치하며, 가중치가 변할 때 현재 가중치×블록 차분과는 다를 수 있다. 6개월 내 결측은 보간하지 않는다. 로딩·설명비는 별도로 존재하지 않는다. build_model.py 및 reweight_saved.py는 마지막에 derive_momentum.py를 실행한다. 아래 과거 설명 중 독립 Momentum 추정에 관한 내용은 이 변경으로 대체된다.

# 내 버전 GDP 비중 가중 PCA

7개국(US, UK, FR, DE, CA, JP, AU), YoY/Momentum 2개 버전. 독립 폴더이며 기존 BlackRock PCA를 실행하거나 수정하지 않는다.

## 실행

- `update.cmd`: Haver 장기 자료 재수신 → 계산 → 검증 → HTML → 대시보드 공개 스냅샷 동기화. 배포/커밋은 하지 않는다.
- `python -X utf8 build_model.py`: 저장한 현재 빈티지 원자료로 재계산.
- `python -X utf8 test_model.py`: 의미 있는 계산 검증.
- `python -X utf8 build_dashboard.py`: 화면 재생성.

`index.html`을 열면 국가별 차트, 히트맵, 지출항목 기여분, GDP 비중, 입력별 경제적 부호·로딩을 볼 수 있다.

`classification_signs.html`은 260개 전체 국가별 분류·부호표다. 입력 부호, 실제 부호 있는 하위 로딩, 상위 C/I 로딩과 GDP 가중치까지 고려한 최종 반영 방향, 현재 PCA 점수의 부호를 구분한다. `classification_signs.csv`와 `component_signs.csv`로 내려받을 수 있다. `build_dashboard.py` 및 `update.cmd` 실행 시 이 표도 함께 갱신된다. 계산값이나 부호 규칙을 바꾸지 않고 저장된 결과를 읽어 만든다.

## 선택

기준은 `outputs/gdp_expenditure_review/report_data.json`의 검토 결과. 확인한 월별 대안을 사용하며 미확보 4개는 제외한다. 원본과 Haver 수치가 일부 다른 후보는 Haver 정의로 사용한다. 이름을 Bloomberg 동등계열로 바꾸지 않는다.

동일 원계열의 수준/전월비/전년비, 확정한 동일 개념의 SA/NSA·단위 중복은 대표 코드로 통합한다. 같은 개념의 다른 범위(총계/하위항목)는 별도 지표일 수 있다. 완전한 경제개념 독립성을 주장하지 않는다. 현재 260개는 공통·참고 블록을 포함한 수이다.

## 계산

1. YoY: 수준 자료 3개월 평균의 12개월 로그차분, 이미 전년비 자료는 3개월 평균, 비율·심리는 수준. Momentum: SA 수준은 3mma의 3개월 로그차분, NSA 수준은 전년비 3mma의 3개월 변화, 비율은 3mma 차분. 재고 잔액은 월간 차분의 3mma, 재고비율은 변화량.
2. EWM z-score 및 EWM 상관행렬. 반감기 YoY 24개월 / Momentum 12개월. 상관은 pairwise complete observations로 계산하고 최소 12개 공통 관측을 요구. 음의 고유값은 작은 양수로 투영하여 PSD 보정.
3. 사용자가 요청한 경제적 방향 고정: 실업·실업수당·해고·장기실업·도산은 -1, 일반 활동은 +1. 저축률/저축의향/총이직률도 단기 소비 해석상 -1이라는 명시적 가정. 방향이 애매한 계열은 화면 표시.
4. 부호 정렬 후 `max v'Rv subject to v>=0, ||v||2=1`을 다중 초기값 projected power iteration으로 근사. 일반 무제약 PCA와 다르며 전역 최적해를 보장하지 않는 제약 성분. 단순히 고유벡터 절댓값을 취하는 방식이 아니다. 양의 로딩만 허용하며 0 로딩은 가능.
5. 소비실적·고용소득·소비심리 별로 계산 후 C를 구성. 설비비주거·주택에서 I 구성. 각 단계 점수는 EWM 표준화. 단일지표 항목은 표준화 지수로 별도 표시. 모든 계층에서 같은 방향 제약을 적용.
6. 최근 4개 분기의 명목 지출액 합/명목 GDP 합으로 각 구성비를 계산. I는 총고정투자에서 일반정부 고정투자를 차감한다. 공기업은 국가별 국민계정 기업부문 분류를 따른다. 일반적으로 분기말 3개월 뒤 적용하며, 일반정부 투자 상세가 늦은 일본은 9개월 지연 규칙을 적용한다. 새 분기 구성비가 모두 확보되기 전에는 마지막 완결 가중치를 유지한다. 수입 가중치는 음수, 재고증감 가중치는 관측된 부호 유지. 미래 분기 가중치를 과거 월에 적용하지 않는다. 이 지연 규칙은 실제 과거 발표일 복원은 아니다.
7. 종합지수=가용 지출 블록 PCA×각 GDP 비중의 합. 제외/결측 비중을 100%로 재분배하지 않는다. C/I/X/M 필수 블록과 가용 항목 절대가중치 80%를 요구. C는 소비실적이 있어야 한다. 필요한 하위블록이 모두 있어야 C/I를 표시한다.

## 해석상 범위

- 지수는 GDP 성장률 또는 성장기여도 %p가 아니다. 지출 비중으로 가중한 표준화 경기 신호다.
- 2026-10-28 사용자 선택에 따라 정부소비와 일반정부 투자는 합산에서 제외한다. 원자료 부족 때문이 아닌 분석 범위 선택이다. 일반정부 투자 비중은 화면에서 제외 항목으로 별도 표시하며 다른 항목에 재배분하지 않는다. `investment_scope.json`에 각국 차감 코드·단위·지연 규칙을 기록했다. 월별 자본재·주택 대리지표 중 일부는 구매자를 민간/정부로 분리하지 못하므로 순수 민간 거래액으로 주장하지 않는다. 프랑스 I는 주택 지표 중심이다.
- 생산/총수주/무역수지/월별 GDP는 별도 참고 블록. C/I/X/M에 억지로 중복 합산하지 않는다.
- 수입의 음의 비중은 지출 회계식을 따른다. 수입 증가가 경기 악화라는 인과 해석은 금지.
- 재고 PCA는 명목 재고 변화·비율의 대리지표. 실질 GDP 재고증감과 다르다. 재고증감 GDP 비중이 음수면 그 부호가 가중치에 반영된다.
- 중간/말단 결측을 보간하지 않는다. 관측 기준월과 수신일을 구분한다.
- 사용 자료는 현재 개정판이며 실시간 빈티지 nowcast/backtest가 아니다. EWM·방향·가중치의 시계열 계산에는 미래 관측을 사용하지 않지만 원자료 개정 영향은 존재한다.
- 원본 BlackRock 파일 해시는 최초 검토 증거와 이번 실행 직전 상태를 각각 저장한다. 매번 해당 실행 중 원본이 변경되지 않았는지 검증하므로 BlackRock의 별도 정상 갱신을 막지 않는다.

## 2026-10-28 전처리 검토

CFNAI 공식 방법론과 McCracken & Ng의 FRED-MD 문헌에 비추어 수준/증가율 분리를 점검했다. 호주 경제전망 2개·구매적기 1개는 소비심리 수준으로 수정했고, 가계재정 2개는 전월비 대신 같은 설문 SA 수준 코드(`ausvcfl`, `ausvcfn`)로 교체했다. 미국 총근로시간 지수 `litpriva`는 평균근로시간과 달리 규모 변수이므로 성장률로 수정했다. 보충 API 조회 증거는 `outputs/pca_methodology_audit/government_checks.json`에 있다. 일반 갱신도 대체 코드들을 재조회한다.

문헌이 현재 모든 설정을 입증하는 것은 아니다. FRED-MD는 실업률·가동률을 차분하며, 현재 수준형 처리의 적절성은 별도 비교가 필요하다. YoY 12개월·EWM·비음수 제약·GDP 구성비 합산은 이 모델의 선택이다. 표준화 후 0은 PMI 50 같은 절대 중립 기준이 아니며, GDP 성장률 예측력이 검증된 모델은 아니다. 전체 260개 변환표와 ADF/KPSS 보조 진단 및 남은 검토 사항은 위 보고서에 저장했다.
