# PCA III — BlackRock 참조 지표만 사용

사용자가 제공한 BlackRock 패널 목록에서 Haver 대응이 확인된 월별 지표만
사용한다. 원본 BlackRock 티커·산식의 완전한 재현은 아니다. 기존 PCA와
PCA II의 화면·계산 결과는 변경하지 않는다.

- 미국·영국·독일·캐나다·일본·호주, 최초 생성 시 162개 고유 시계열.
- 프랑스는 제공된 목록에 자체 패널이 없어 제외. 유로존은 사용자 지시로 제외.
- 제조업은 PCA II와 동일하게 Capex(기업활동)에 포함한다.
- 독일·일본은 Housing 참조 지표가 없으므로 해당 축을 결측으로 보존한다.
  Growth는 나머지 세 축을 같은 GDP 비중으로 합산하며 비중 재배분은 없다.
- 기존 입력 중 BlackRock 참조와 대응되지 않는 고용·임금 등은 추가하지 않는다.
- 개념 대응·대리계열·미확인·비월별·중단·중복은 전체 198개 참조 검토표에 남긴다.

## 계산

`PCA_Four_Axis/build.py`의 같은 엔진을 `reference_only=True`로 실행한다.
지표 분류·변환·경제적 방향은 PCA II와 동일하다. 입력 표준화, 상관행렬,
출력 표준화 모두 24개월 반감기이며 로딩 ≥ 0 제약(0 허용)을 유지한다.
Momentum은 완성된 Level의 최근 3개월 평균에서 직전 3개월 평균을 뺀 값이다.

GDP 비중은 PCA II의 동결된 연초 스냅샷과 정확히 일치하도록 가져온다.
새해는 같은 발표 지연 규칙으로 생성한다. Export는 명목 총수출/GDP × 0.5.
기존 국가·연도 비중은 갱신 과정에서 변경하지 않는다.

자료가 있는 모든 편입 축과 소비실적·수출실적 각각 한 개 이상이 있어야
Growth를 게시한다. 자료 보간은 하지 않으며, 부문 차트의 마지막 월도
Growth의 유효월에 맞춘다. 원지표 드릴다운은 최신 수신 관측까지 표시한다.

## 갱신 및 배포

- `update.cmd`: 공유 Haver 수집 → PCA III 계산 → 수치 검증 → HTML → 게시 스냅샷.
- `update.cmd --cached`: 저장된 Haver 데이터로 동일한 절차 실행.
- QAE의 `run_qae.py` web 단계에 연결되어 있다.
- PCA II의 `run_update.py`도 완료 후 PCA III를 저장 데이터로 갱신한다.
- `macro_hub`의 build는 `sync_pca_iii.mjs`로 로컬 결과를 복사한다.
  Vercel에서는 커밋된 `public/embeds/pca-iii` 스냅샷을 검증한다.
- 공개 경로 `/pca-iii`, PCA II 다음 탭.

Level과 Momentum을 동시에 위아래로 표시한다. 국가별 끝값, 종합·부문
기여분, 전체 국가의 섹터 히트맵, 원지표 추이와 클릭 가능한 Swirlogram을
제공한다. 주요DM은 6개국 동일가중이며 Housing에 한해 자료가 있는 4개국을
고정 구성으로 사용한다. 범례 숨김과 월별 결측으로 구성국을 변경하지 않는다.

검증: `test_model.py`, `test_dashboard.py`.
