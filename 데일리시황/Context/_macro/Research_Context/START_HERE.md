## 앞서 정한 작업 순서와 현재 위치

원문 PDF → 원문 검색 DB → IB·국가·쟁점별 견해 이력 → WECO 발표와 대조 → 국가 판단 초안 → 사용자 승인.

- **완료:** 현재 폴더 PDF의 텍스트 적재, 내용 중복 판별, 페이지 연결, 제목 기반 국가·주제 검색, 새 파일만 추가하는 반복 실행 검증.
- **완료:** 5개 IB·6개 국가의 현재 견해·전제·원문 근거와 직접 대조한 유지/변경 이력. 초기 유로존 시험 주장 8개도 보존했다.
- **완료:** ecocal 파일의 WECO 발표값·수정치 연결, 요청받아 작성한 지표 요약·IB 코멘트 저장과 수치 변경 재검토, 기존 INDEX에 별도 거시 맥락 뷰 연결. 지표 입력으로 해석 준비 묶음을 생성하는 기능도 유지한다.
- **다음:** 미검토 원본의 과거 전환점·부족한 정책 경로 보강과 새 보고서에 대한 근거 확인. 숫자/화면 갱신만으로 새 IB 견해를 만들지 않는다.
- **아직 하지 않은 것:** 모든 PDF의 의미 해석 완료, 실제 거시지표 검증, 사용자 판단 승인, 자동 일일 보고서·예약 실행, 공개 사이트 게시.

현재는 프로그램을 실행할 때 갱신하는 방식이다. 폴더에 파일을 넣기만 했을 때 자동으로 시작하는 감시 기능은 붙이지 않았다. 별도 다운로드 작업을 방해하거나 원문을 이동·삭제하지 않는다.

## 새 자료를 넣은 뒤

이 폴더에서 아래 명령을 실행한다. 기존 파일은 건너뛰고 실행 시작 전에 도착한 새 PDF를 처리한다.

```powershell
python -X utf8 .\research_context.py ingest
python -X utf8 .\research_context.py packet --country all
python -X utf8 .\verify_context.py
```

새 파일이 다른 폴더에 있다면 README의 `--raw` 예시를 사용한다. Python에 PyMuPDF가 필요하다. 원문 추출·검색은 로컬에서 실행하며 유료 API를 호출하지 않는다. 새 자료에 대한 AI 해석은 이 앱에서 원문을 검토해 수행하고, 근거 검증을 거쳐 살아있는 IB 모듈에 추가한다.
