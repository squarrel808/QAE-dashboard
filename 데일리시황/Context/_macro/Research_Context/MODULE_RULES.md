# IB 모듈을 읽고 갱신할 때

이 자료는 사용자의 매크로 판단을 돕는 근거 저장소다. 현재 저장된 견해는 모두 사용자 검토 전 초안이다.

2026-09-15 운영 구조: 사용자 입구는 `데일리시황/표_업데이트/index.html`이다. `WECO/index.html`(지표 요약·IB 코멘트)과 `WECO/macro_views.html`(IB별 Growth / Inflation / 통화정책의 거시 맥락)을 함께 유지한다. 아래 지표 우선 원칙은 독립적인 거시 뷰 페이지를 없애라는 뜻이 아니다.

1. `output/living_ib/START_HERE.md`와 `COVERAGE.md`에서 기준일·범위·공백을 확인한다. 지표 해석은 `지표명·동의어 + 국가/지역 + 발표 전후 시점 + IB`의 지표 우선 검색으로 시작한다. `review_queue.json` 또는 `dashboard_data.json`의 `search_candidates`를 먼저 읽고 원문 전체 페이지를 확인한다. 필요한 국가·지표에 해당하는 각 IB의 상태와 원문 페이지만 읽으며, 검색 대상 전체를 이미 해석한 것으로 말하지 않는다.
2. 각 IB의 전망과 전제를 독립적으로 추적한다. IB의 고정 성격이나 과거 평균을 만들어 현재 견해로 대체하지 않는다. IB들 사이 합의·차이는 원문 비교 후 별도로 설명한다.
3. 금리 기본 경로, 위험 시나리오, 성장·물가 전망, 지표 발표 전 예상, 실제 발표 후 판단을 구별한다. 확률·임계값·시작 시점은 원문에 있는 경우만 IB 주장으로 기록한다.
4. 지표 발표값·컨센서스·종전·수정치를 공통 단위와 기간으로 확인한다. 사실 출처와 IB 해석 근거를 각각 연결한다. 시장 가격 반응은 별도 실제 데이터를 확인했을 때만 설명한다.
5. broad growth/inflation 뷰는 구체적 지표 코멘트를 대신하지 않는다. 정확한 지표 직접 언급이 없을 때만 보조 배경으로 사용한다. 새로운 지표에 대한 추론에는 “AI 해석 초안”을 표시한다. 어느 기존 전제가 강화/약화/미판정인지 설명하되 실제 IB의 새 발언으로 쓰지 않는다. 이 추론으로 IB 상태를 덮어쓰지 않는다.
6. 새 IB 보고서를 근거로 상태를 갱신할 때는 이전 원본과 동일 쟁점을 비교한다. 유지/변경을 나누고, 새 고유 ID와 이전 ID를 연결해 기록한다. 원문에 과거 변경이 언급됐지만 이전 원본은 못 찾았다면 직접 대조 미완료로 표시한다.
7. 날짜·숫자·시나리오가 충돌하면 제한에 기록하고, 확인하지 못한 수치를 채우지 않는다. 글로벌 보고서의 국가 담당자 장과 다른 지역 보고서의 짧은 요약은 범위를 구별한다.
8. 원본·기존 견해·사용자 승인 메모를 보존한다. 새 근거 입력은 `living_ib.py import-views`, 출력 갱신은 `build`, 검증은 `verify`를 사용한다. 오류가 나면 근거를 고친 후 입력한다.
9. 국가 판단은 사실 → IB별 전제 변화 → 공통점/차이 → AI 판단 초안 → 다음 확인 조건 순으로 작성한다. 사용자가 승인하기 전 승인된 판단으로 표시하지 않는다.
10. 지표 해석 기능이 새 보고서를 자동으로 읽거나 일정을 자동 등록한다고 말하지 않는다. 현재 구현된 자동화는 로컬 적재·검증·상태 선택·이력 출력·해석 준비 묶음 생성이다.
11. 지표 해석은 결과 수치 → 짧은 한국어 핵심 요약·다음 확인점 → IB별 요약·AI 비교 코멘트로 작성하여 `ecocal_dashboard/authored_commentary.json`과 기존 대시보드에 반영한다. 긴 원문을 요약 대신 붙이거나 검색 발췌를 검토된 코멘트로 표시하지 않는다. 원문은 출처 제목·발행일·페이지와 연결하여 접는다.
12. 저장한 지표 요약은 국가·발표일/시각·지표·대상 기간과 실제·예상·종전·수정·단위·배율·통화 스냅샷이 일치할 때만 재사용한다. 불일치는 재검토로 표시한다. `reaction` / `preview` / `related`의 시점·대상 차이를 유지하고 관련 분석은 범위 제한을 밝힌다.
13. 거시 맥락 화면에는 저장된 핵심 견해·전제·리스크/확인 질문·이전 견해와의 변화·제한·출처를 보여준다. 호주·글로벌 등 기존 지역을 캘린더 지역에 맞춰 없애지 않는다. 유로존 견해를 개별 회원국의 독립 견해로 복제하지 않고, 에너지 위험과 시장금리 전망은 물가·정책 결정 자체와 구분한다. 없는 하우스·쟁점은 공백으로 남긴다.
14. HTML 생성일, 지표 코멘트 검토일, 거시 견해 자료일, 검색 DB 최신 보고서일을 분리한다. 기본 재생성은 모델 API 호출 없이 저장 내용을 읽는 작업이다. 새 요약·해석은 사용자가 요청한 이 앱의 모델 작업이며, 새 거시 견해는 원문 대조 후 새 ID/이전 ID로 추가한다. 지표 AI 추론을 새 IB 하우스뷰로 승격하지 않는다.
