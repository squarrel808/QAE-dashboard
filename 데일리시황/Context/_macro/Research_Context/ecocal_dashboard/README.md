# 경제 캘린더와 IB 해석

2026-09-11부터 기본 갱신은 **숫자와 검토된 기존 IB 근거 연결**입니다. 새 AI 해석은 사용자가 별도로 요청할 때 작성합니다. 저장된 `authored_commentary.json` 요약은 검토 당시 수치와 일치하면 기본으로 표시합니다. `--include-reviewed-interpretations`는 과거 고정 해석 템플릿을 추가 표시하는 옵션일 뿐, 저장 요약을 켜거나 새 AI 분석을 실행하는 스위치가 아닙니다.

사용자 진입점은 **`데일리시황/표_업데이트/index.html`**입니다. 국가 → 발표월 → 경기·물가·통화정책을 선택합니다. 기본으로 실제값이 있는 지표를 표시하며, ‘전체 일정’으로 최신 원본의 미발표 항목도 볼 수 있습니다. 새 원본의 이동 기간에서 벗어난 실제값 수록 지표는 `indicator_history.json`에 누적해 과거 기록으로 표시합니다. 같은 지표가 최신 원본에 다시 있으면 최신 수치를 우선하고, 저장 해석은 수치 스냅샷이 맞을 때만 표시합니다. 별도 `dist/index.html`은 레거시 단독 출력이며 메인 대시보드 대신 사용하지 않습니다. HTML에는 데이터가 포함되어 서버 없이도 열립니다. 원본 PDF는 기존 경로에 있어야 합니다.

## 두 화면의 역할 — 2026-09-15 반영

같은 실행 폴더의 `WECO/index.html`은 **지표별 요약·IB 코멘트**, `WECO/macro_views.html`은 **IB 거시 맥락 뷰**입니다. 두 메뉴를 기존 메인 INDEX와 실행별 INDEX에 연결하고 두 화면 사이에서도 이동할 수 있게 유지합니다. 지표 중심 개편 때문에 별도의 성장·물가·통화정책 맥락 화면을 없애거나 접힌 배경 속에만 남기지 않습니다.

거시 화면은 국가/지역별로 GS·JPM·Citi·BofA·HSBC를 행, Growth / Inflation / 통화정책을 열로 비교합니다. 핵심 견해·전제·리스크/확인 질문·이전 견해와의 변화·제한·자료일·출처를 먼저 보이고 긴 원문과 과거 이력은 접습니다. 호주·글로벌 등 기존 거시 지역을 캘린더 지역 목록에 맞춰 누락시키지 않습니다. 유로존 뷰를 독일·프랑스·이탈리아의 독립 뷰로 복제하지 않습니다. 에너지 위험은 물가 전망의 보조 쟁점, 시장금리 전망은 정책 결정과 별개임을 표시합니다.

거시 페이지는 `living_ib.sqlite3`와 `reviewed_comments.json`의 `views`를 읽고 원문·날짜·하우스·이력을 검증하여 생성합니다. 기존 수치 전망은 기간·단위·시나리오를 보존해 별도로 보여줍니다. 지표 작성물 `authored_commentary.json`을 거시 전망으로 승격하지 않으며, 두 DB나 기존 견해 이력을 수정하지 않습니다.

2026-09-15 복원 당시 현재 견해 58건(기존 55 + 보강 3), 이전 17건, 저장 수치 전망 10건을 표시했습니다. 거시 견해 최신 자료일은 9월 8일, 검색 DB 최신 보고서일은 9월 15일이었습니다. 복원은 새 보고서 전체 분석이 아닙니다. 현재 수량과 날짜는 메인 `latest.json`의 `weco.macro_views`를 확인합니다. `historical_views`는 현재를 포함한 전체 이력 수, `prior_views`는 이전 견해만의 수입니다.

## 요약과 코멘트 표시 원칙

지표를 선택하면 **결과 수치 → 핵심 요약·지표 해석 → 다음 확인점 → IB별 요약·AI 비교 코멘트** 순서로 보여줍니다. 원문 전체 페이지를 읽고 지표·국가·대상 기간을 확인한 뒤 짧은 한국어 문장으로 작성합니다. 긴 원문 발췌와 미검토 검색 후보는 기본적으로 접습니다. 관련 보고서가 없는 IB를 일반 growth/inflation 문구로 채우지 않습니다.

사용자가 요청해 작성한 요약은 `authored_commentary.json`에 지표별로 보관합니다. 원문에 대한 IB 요약과 AI의 수치 비교·판단을 구분하며, 모든 작성물은 사용자 검토 전 초안입니다. 발표 전 전망, 발표 후 반응, 다른 기간·세부지표의 관련 분석을 구분하고 관련 분석에는 범위 제한을 반드시 표시합니다. 보고서와 원본 숫자가 다르면 그 차이도 표시합니다.

이 파일에는 정확한 지표 식별자, 작성시각, 원문 페이지·인용, 실제·예상·종전·수정·단위의 검토 당시 값이 저장됩니다. 다음 갱신에서 어느 값이든 달라지면 기존 해석은 숨기고 재검토로 표시합니다. 숫자 갱신 자체가 새 해석을 작성하지는 않습니다.

실제 재사용 검사는 국가·발표일·시각·지표명·대상 기간과 `survey, actual, prior, revised, scale, currency, unit` 전체를 대조합니다. 행 번호 변경만으로 연결을 끊지는 않습니다. 근거 인용 일치는 한국어 의미 해석의 정확성까지 자동으로 보장하지 않으므로 사용자 검토 전 초안 표기를 유지합니다.

## 정보 구분

- **발표 후 직접 코멘트**: 해당 국가·지표·대상 기간을 다룬 보고서를 읽고 요약한 내용입니다.
- **발표 전 직접 전망**: 해당 지표의 발표 전 수치 전망 또는 프리뷰입니다. 사후 반응이 아닙니다.
- **기존 뷰 기반 AI 해석**: 현재 저장된 관련 IB 견해에 비춰 작성한 조건부 해석입니다. IB의 실제 발언·전망 변경으로 기록하지 않습니다.
- **근거 미확보**: 검토한 자료에 연결 근거가 부족합니다. 전체 보고서에 언급이 없다는 의미는 아닙니다.

기존 B~K 양식과 Bloomberg A~L 원본 양식을 모두 읽고 원본 셀을 보존합니다. 새 양식의 국가 코드는 표준 국가명으로 연결하고 퍼센트 셀 서식과 k/m/b/t·통화기호를 반영합니다. `#N/A`와 빈 셀은 0으로 계산하지 않습니다. J가 있으면 수정 종전값으로 I를 대신해 차이를 계산하고 수정 폭도 따로 표시합니다. PMI·GDP 확정치의 I는 같은 기간 속보치일 수 있어 월간 추세와 구별합니다. 시간대는 원본에 명시되지 않아 변환하지 않습니다.

프랑스·독일·이탈리에 기존 유로존 견해를 적용하면 지역 견해에 기초한 추론임을 표시합니다. 통화량·국제자금흐름·외환보유액은 통화정책의 보조지표로 분류하고 정책 결정 자체와 구분합니다. 월은 발표일 기준이며 F열의 대상 기간도 별도로 보관합니다.

## 갱신

메인 갱신은 `데일리시황/데일리_표_업데이트.cmd`를 사용합니다. `____Rawdata___`의 수정일이 가장 최근인 `ecocal*.xlsx`를 읽고 저장된 요약·기존 IB 근거를 연결합니다. **새 보고서를 자동으로 이해하거나 새 코멘트를 작성하지는 않습니다.** 해석 요청을 받으면 원문 검토 후 `authored_commentary.json`에 요약·코멘트를 작성합니다. 기존 `reviewed_comments.json`의 직접 연결과 견해 이력은 보존합니다. 행 번호가 바뀌어도 국가·발표일·시각·지표명·기간이 같으면 연결됩니다. `refresh_dashboard.cmd`는 레거시 단독 결과용입니다.

직접 코멘트와 기존 IB 근거의 문서·페이지·인용·파일 존재를 빌드할 때 검증합니다. 본문 의미 검증은 별도의 보고서 검토입니다. `curate_comments.py`는 이번 검토를 재현하는 개발 기록이며 갱신 명령에는 포함되지 않습니다.

정상 `build_dashboard.py` 실행은 `build_macro_views.py`도 호출하고, 기본 데일리 실행기는 새 거시 페이지를 결과 목록에 넣습니다. 저장된 요약을 보여주기 위해 `--include-reviewed-interpretations`를 켤 필요는 없습니다. 해당 옵션은 과거 고정 해석 템플릿 표시용이고 새 AI 분석 스위치가 아닙니다. 로컬 숫자 읽기·검색·기존 내용 재표시는 LLM API를 호출하지 않습니다. 사용자가 새 원문 요약·해석을 요청하면 이 앱의 모델 사용량이 들고, 결과를 대화창에만 남기지 않고 저장 파일과 대시보드에 반영합니다.

생성 시각·지표 검토일·거시 견해 자료일·검색 DB 최신 보고서일을 별개로 표시합니다. 이번 게시본의 `new_ai_interpretations: true`는 9월 15일에 사용자가 새 지표 해석을 요청한 기록이며, 기본 실행이 매번 새 해석을 생성한다는 의미가 아닙니다.

입력 범위·지역·지표 수는 메인 결과의 최신 기록을 확인합니다. 과거 월은 이전 성공 실행에서 실제값이 확인된 지표만 누적 표시하며, 없는 관측값을 만들어 채우지 않습니다. 누적 이력 도입 이전에 저장된 실행 결과가 없는 날짜는 소급 복원되지 않습니다. 원본 엑셀과 기존 두 리서치 DB는 읽기 전용으로 사용합니다.

## 파일

- `dashboard.html`: 화면 템플릿
- `build_dashboard.py`: 최신 ecocal 읽기·분류·근거 연결·결과 생성
- `macro_views.html`: 국가별 IB 거시 맥락 비교 템플릿
- `build_macro_views.py`: 저장된 거시 견해·이력·수치 전망을 읽기 전용으로 검증·선택하고 HTML/JSON 생성
- `reviewed_comments.json`: 이번에 확인한 직접 코멘트와 보강 견해
- `authored_commentary.json`: 원문 검토로 작성한 짧은 지표 요약·IB 요약·AI 코멘트와 검토 당시 수치
- `데일리시황/표_업데이트/index.html`: 사용하는 메인 결과
- `데일리시황/표_업데이트/runs/<요청시각>/WECO/index.html`·`dashboard_data.json`: 사용하는 지표 화면과 데이터
- 같은 실행의 `WECO/macro_views.html`·`macro_views_data.json`: 거시 맥락 화면과 데이터
- 같은 실행의 `WECO/review_queue.json`·`validation.json`: 지표 검토 대상과 검증 기록
- `dist/index.html`: 레거시 단독 결과
- `dist/dashboard_data.json`·`dist/validation.json`: 레거시 단독 실행의 데이터·검증 결과. 메인 최신 실행과 혼동하지 않습니다.
- `serve_dashboard.py`: 필요 시 원문 PDF까지 연결하는 이 PC 전용 미리보기

수동 실행 예: `python build_dashboard.py --as-of 2026-09-11` 또는 `python serve_dashboard.py`.
