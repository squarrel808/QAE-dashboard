# 매크로 전용 Chrome 수집 (포트 9223)

`run_macro_separate_chrome.py`를 기존 `macro_bulk_downloader.py`와 같은 폴더에 둡니다.

- **매크로 전용 프로필 `_macro\.collector\chrome-profile` / 포트 9223**을 사용합니다.
- 보따리의 `C:\selenium_profile` / 포트 9222와 프로필·프로세스를 분리했습니다.
- 9223 포트가 다른 프로필이면 실행을 거부합니다.
- 전용 Chrome이 없으면 따로 열고, 수집 중 새로 열린 전용 창은 최소화합니다.
- 비밀번호를 읽거나 복사하지 않습니다. 기존 로그인 세션을 사용합니다.
- 종료해도 Chrome 전체를 닫지 않습니다. 수집기가 만든 탭만 기존 수집기가 정리합니다.
- 보따리와 별도 Chrome 프로세스에서 실행할 수 있습니다. 로그인은 매크로 전용 프로필에 별도로 유지합니다.

## 실행

이 폴더에서 아래 명령으로 실행합니다.

```powershell
python .\run_macro_separate_chrome.py
```

기본값은 **실행일 기준 최근 3개월**, 기존 원본 PDF 폴더와 중복 확인 기록을 그대로 사용합니다. 이미 저장된 정상 PDF는 다시 저장하지 않습니다.

```powershell
# 연결만 확인
python .\run_macro_separate_chrome.py --check

# 사이트 로그인/목록 접근 확인 (PDF 수집 없음)
python .\run_macro_separate_chrome.py --check-sites

# 전용 Chrome 로그인 탭을 표시하고 종료 (수집 시작 안 함)
python .\run_macro_separate_chrome.py --open-login

# 최근 3개월 목록만 확인
python .\run_macro_separate_chrome.py --mode scan --months 3

# 특정 날짜 범위의 원본 다운로드
python .\run_macro_separate_chrome.py --start 2026-06-08 --end 2026-09-08

# 인증이 필요한 경우에만 전용 창에서 직접 로그인
python .\run_macro_separate_chrome.py --mode login --houses HSBC

# 현황 확인
python .\run_macro_separate_chrome.py --mode status
```

로그인이 필요한 경우 전용 Chrome을 작업 표시줄에서 열어 직접 인증합니다. 로그인 실행에서는 창을 자동으로 최소화하지 않습니다.

## 저장 위치

- PDF: `outdated\HSBC`, `outdated\GS`, `outdated\JPM`, `outdated\Citi`, `outdated\BofA`
- 실행 기록: `.collector\logs\YYYY-MM-DD\run_*.log`, `run_*.json`, `.collector\logs\latest_run.json`
- 파일 목록/상태: `.collector\manifest.csv`

별도 Chrome 연결 성공은 전체 다운로드 완료를 뜻하지 않습니다. 누락/로그인/사이트 형식 변경은 기존 수집기의 실행 기록에서 별도로 확인해야 합니다.
