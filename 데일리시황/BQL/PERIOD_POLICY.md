# 성과 기간 공통 기준 · 2026-11-03

5D·1W·주간·주보는 시장별 최신 유효 종가 ÷ 5거래일 전 유효 종가 − 1로 통일한다(6개 종가, 5개 수익률 구간). 휴장·주말·미마감 이월 열은 제외한다. 시장별 실제 시작일·종료일과 원본 SHA256을 표시하고, 6개 종가가 부족하면 5D를 산출하지 않는다. 사용자가 특정 달력 주간을 명시한 경우에만 별도 기간으로 계산하고 5D와 구분한다.

- 공통 구현: `period_policy.py`. 섹터 표·AI 보고서·아침시황·대시보드가 같은 거래일 판별 함수를 사용한다.
- 실거래일은 구성종목의 유효 가격 중 2% 이상이 직전 유효 종가에서 변한 열로 판별한다. 가격 변화 기반 추정이므로 공식 거래소 달력의 대체물은 아니다.
- 같은 시장·기준일·원본·종목 범위에서는 5D 시작일과 종료일이 반드시 같아야 한다.
- 날짜 또는 원본이 다른 파일은 최신 비교 검증을 통과한 것으로 표시하지 않는다.
- 수익률은 배당 제외, 그룹 집계는 시작일 유효 시총가중.
- 과거 실행 결과·백업은 당시 기록이며 현재 생성 규칙으로 재사용하지 않는다.
