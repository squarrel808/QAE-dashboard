## 왜 기존 문서가 8월 21일이었나

사용자가 붙인 TOPIX 데이터는 9월 4일까지 실제로 존재했다. 그러나 최신 Master에는 9/2·9/3·9/4 종가만 있어 5D 기준점인 8/28이 없었다. 기존 생성 코드는 이 경우 8/21에서 끝나는 옛 역사 파일로 자동 후퇴했다. 즉 입력 누락이 아니라 silent fallback 설계 문제였다.

이번 교정은 현재 1,635종목 전부의 8/28~9/4 종가를 복원했다. 로컬 BQL과 겹치는 9/2~9/4 가격 4,905건의 중앙 절대오차는 0이고 최대 오차도 사실상 0이었다.
