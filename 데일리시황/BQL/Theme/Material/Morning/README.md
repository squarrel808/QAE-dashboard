- 미국 S&P 500, 유럽 STOXX 600, 일본 TOPIX, 항생 Hang Seng의 섹터·산업그룹 1D·5D·1M·3M·6M 수익률은 **각 기간 시작일 시가총액 가중평균**이다. AI 밸류체인은 이후 사용자 정정에 따라 **유효 종목별 가격수익률의 단순평균(동일가중)**을 사용한다. 가격 결측 종목과 배당은 제외하고 표 아래 작은 각주에 계산 기준을 표시한다.
