① 입력 부호 + / −변환한 지표가 상승할 때 해당 블록을 어느 방향으로 읽는지입니다. 예: 실업률 −, 소비·생산 +. 국가별 분류표에 표시합니다.
② 실제 PCA 로딩 부호경제적 방향 × 비음수 PCA 로딩입니다. 입력 부호가 −여도 해당 시점 로딩이 0이면 0으로 표시합니다. YoY·Momentum을 나란히 비교합니다.
③ 현재 PCA 값의 + / −이번 기준월에 산출된 지수가 0선 위인지 아래인지입니다. 지표의 고정 입력 부호와 다릅니다. 아래 국가별 점수표에서 확인합니다.

GDP 합산 방향은 한 번 더 구분합니다. 수입은 지표 블록 안에서 +지만 GDP 가중치가 −라 종합지수에는 반대로 들어갑니다. 재고는 GDP 비중의 부호에 따라 달라집니다. 공통 경기·무역수지·GDP 검증용은 참고용으로만 표시합니다. 부호는 표준화된 변환 입력 기준이며 GDP 성장률의 인과효과가 아닙니다.

국가별 분류 현황

숫자는 중복 정리 후 원계열 개수입니다. C 안의 고용·소득/소비심리는 민간소비 설명 블록입니다.

현재 국가별 PCA 값은 +인가, −인가?

각 칸의 위 = YoY, 아래 = Momentum. 부호는 실제 계산값 기준입니다. 정부소비와 미확보 재고는 미산출로 표시합니다.

국가별 지표 분류표

각 지표 앞의 +/−는 고정한 입력 부호입니다. 이름 위에 마우스를 올리면 전체 Haver 정의와 코드를 볼 수 있습니다.

지표별 실제 로딩과 GDP 합산 부호

위 국가·분류·검색 필터와 연결됩니다. 부호 있는 로딩 = 입력 부호 × 항목 내부 로딩이며, 계층 표준화 때문에 최종 지수의 회귀계수나 민감도는 아닙니다. GDP 합산 방향은 소비/투자 상위 로딩과 GDP 비중 부호까지 확인했습니다. 절댓값 ≤ 10⁻⁸은 표시상 0으로 취급합니다.

분류·부호에 포함한 예외

  • 저축률·저축의향·총이직률은 단기 소비 관점에서 −라는 모형 가정을 적용했습니다.
  • 수입 증가 자체를 경기 악화로 보지는 않습니다. GDP 지출식의 차감 부호를 별도 열에 표시했습니다.
  • 재고 블록은 재고 잔액 자체가 아니라 증감·비율 변화입니다. 미국·일본의 이번 GDP 재고증감 비중은 음수이므로 합산 방향이 음수가 될 수 있습니다.
  • 하위 지표 로딩이 양수여도 상위 소비/투자 PCA의 해당 블록 로딩이 0이면 종합지수 반영은 0입니다.
  • 정부소비 월별 지표와 원본 4개(호주 임금 2개·산업생산, 캐나다 단위노동비용)는 미확보로 제외했습니다.
이 표는 저장된 모델 결과에서 생성했습니다. 기존 BlackRock PCA와 새 PCA의 계산값은 바꾸지 않았습니다.
