 QAE 대시보드 일일 자동 갱신 - 사용법

[구성 파일]
  - run_all_0830.bat      : 실제 작업 전체 (크롬 실행 -> PDF 수집/요약
                            -> 데이터 갱신 -> HTML -> JSON 빌드 -> git push)
  - 스케줄등록_0830.bat    : 매일 08:30 작업 스케줄러 등록 (1회만 실행)
  - logs\                 : 날짜별 실행 로그

------------------------------------------------------------
1단계. 사전 준비 (기존 보따리 자동화와 동일)
------------------------------------------------------------
  - C:\selenium_profile 프로필로 각 사이트(Marquee/BofA/HSBC/JPMM)에
    1회 수동 로그인이 되어 있어야 함 (크롬_연동.bat 로 열어서 로그인)
  - report_pipeline\.env 에 ANTHROPIC_API_KEY 필요 (.env.example 참고)
  - gs_api\.env 등 각 폴더의 .env 도 그 컴퓨터에 있어야 함
    (.env 는 git에 안 올라가므로 컴퓨터마다 직접 채워야 함)

------------------------------------------------------------
2단계. 수동 테스트 (스케줄 걸기 전에 꼭!)
------------------------------------------------------------
  "C:\Users\infomax\Documents\python\QAE\_자동화\run_all_0830.bat"
  를 더블클릭 -> logs\오늘날짜.log 를 열어 각 단계 성공 여부 확인.

------------------------------------------------------------
3단계. 매일 08:30 자동 실행 등록
------------------------------------------------------------
  "스케줄등록_0830.bat" 를 1회 더블클릭.
  (기존 보따리 "리서치요약" 작업과 시간이 겹치면 그쪽을 삭제하거나
   시간을 조정: schtasks /Delete /TN "리서치요약" /F)

------------------------------------------------------------
주의
------------------------------------------------------------
  - PC가 켜져 있어야 실행됨. 놓친 스케줄을 부팅 후 실행하려면
    작업 스케줄러(taskschd.msc)에서 해당 작업 속성 ->
    "예약된 시작 시간을 놓친 경우 가능한 빨리 시작" 체크.
  - 로그인 세션이 만료되면 해당 사이트만 실패하고 나머지는 계속 진행됨.
    크롬_연동.bat 로 열어 다시 로그인하면 됨.
  - git push 는 이 컴퓨터에 GitHub 자격증명이 저장되어 있어야 함.
