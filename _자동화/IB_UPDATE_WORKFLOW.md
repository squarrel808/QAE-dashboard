# IB 거시 의견·지표 코멘트 일일 갱신

2026-10-22 사용자는 10월 초 이후의 누락 복구와 두 화면의 지속적인 자동 갱신을 요청했다.

## 성공의 기준

화면 재생성이나 PDF 적재만으로 분석 갱신 성공을 기록하지 않는다. 지표와 거시 의견을 각각 원문 근거로 검토하고, 게시된 데이터의 날짜·개수·미확보 항목을 다시 읽어 확인한다. 자료가 변하지 않은 경우 실제 점검 범위와 무변경 결과를 기록한다.

## 권한과 실패 처리

작업 폴더는 QAE이다. 프로젝트 `.codex/config.toml`에 workspace-write와 on-request를 명시했다. 예약 실행 시작 시 실제 권한을 확인한다. QAE 로그 디렉터리에 작은 임시파일을 생성·삭제해 쓰기를 확인한다. 읽기 전용으로 시작하거나 저장이 거부되면 승인된 도구의 require_escalated 절차로 해당 QAE 저장 작업만 재시도한다. 시스템·조직 제한을 우회하거나 전체 접근으로 변경하지 않는다. 자동 승인도 거절되면 정확한 작업·오류와 마지막 정상 게시일을 알리고 성공으로 표시하지 않는다.

로그는 먼저 `_자동화/ib_interpretation_monitor.py begin`으로 기록한다. `--refresh`의 외부 scheduler_dashboard.html 갱신 실패가 분석 자체를 중단시키지 않도록 별도로 처리한다. 완료 후 finish --run-id ... --record ...를 실행하고 실패는 fail로 기록한다. QAE 자체에도 기록이 불가능하면 대화 알림에 실패를 남긴다.

## 입력·검토

기존 06:30 수집은 다시 실행하지 않는다. 수집 로그와 안정된 신규 PDF를 확인하고 연구 DB를 갱신한다. latest.json에서 실제 WECO 폴더와 입력을 찾는다. ecocal 원본이 갱신되지 않았으면 숫자는 유지하며 새 근거의 해석만 갱신한다.

지표: 신규 수치, 숫자 변경, 미작성·재검토, 새 근거로 의미가 바뀐 기존 지표를 검토한다. 과거 누적 지표도 새 검색 후보를 재생성한다. 지표·국가·대상기간·발표 전후를 맞추고 채택한 원문 페이지 전체를 읽는다. 원문이 없으면 IB 의견을 만들어 넣지 않는다. 숫자만으로 작성한 AI 해석은 근거 미확보로 구분한다. authored_commentary.json의 기존 이력과 수치 스냅샷을 유지한다.

거시: GS/JPM/Citi/BofA/HSBC의 성장·물가·정책금리 원문을 별도로 검토한다. living_ib.py import-views로 새 ID를 추가하고 기존 ID는 수정하지 않는다. 이전 견해와 현재 원문을 모두 대조한 경우 prior_view_id와 유지/변경 판정을 남긴다. 대조하지 않은 경우 uncompared로 표시한다. 지표 AI 추론을 거시 하우스뷰로 자동 승격하지 않는다. 원문 날짜·페이지·인용, 확인한 범위와 미확보 하우스를 보존한다.

## 검증·게시

임시 화면은 build_dashboard.build(..., publish_stable=False)로 생성한다. 임시 생성이 고정 IB_views 입구를 수정해서는 안 된다. 현재 원본과 수치·단위·배율·통화 일치, 각 지표 하우스 5개, 인용·파일·날짜, 초안 상태, 이전 이력 보존, 원본/상태 동시 변경 여부를 검증한다. 정상 결과만 게시한 후 실제 WECO 경로로 build_macro_views.build를 실행해 고정 입구 링크를 갱신한다.

latest.json, 실행 manifest, daily_interpretation_state.json, run_record.json에 지표 검토일·거시 자료일·숫자 원본일·검색 DB 최신일을 분리해 기록한다. 요약 추가/수정 수, 거시 뷰 추가 수, 미작성·재검토 수, 직접 IB 근거 미확보 수를 각각 기록한다. 두 화면에 새 내용이 저장됐는지 재독한다. 입력 손상·검증 실패는 이전 정상 게시본을 유지하고 오류를 알린다.

2026-10-22 복구 자료와 검증은 표_업데이트/interpretation_runs/20261022_recovery에 보존한다. 이 자료를 앞으로 매일 그대로 재게시하지 않는다. 매일 새로운 입력과 원문을 검토한다.
